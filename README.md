# Configurable Armour Suits: Updated

Configure armour equipment grids and inventory bonuses, including the supported Metal and Stars armour. This fork supports both the original and updated Metal and Stars identities while retaining original setting names and configured values. It uses native save migration ownership when replacing the original mod.

Requires Factorio 2.1.24. Native checks covered both Metal identities, configured grids and inventory bonuses, plus the related subplanets and routes. Replace the original Configurable Armour Suits with this fork; both cannot be enabled together.
